# Приглашение Михаила и Татьяны

Статический сайт-приглашение для GitHub Pages: https://mt-061026.github.io/. Публичный репозиторий: https://github.com/mt-061026/mt-061026.github.io. В него загружаются только файлы из этой папки; локальные настройки сервера, ключи и `.env` остаются вне него.

Основные данные пары меняются в `script.js`, тексты и программа — в `index.html`, внешний вид — в `styles.css`. Фотография обложки находится в `cover.jpg`. Стилизованная схема шатра в лесу у адреса декоративная; для навигации есть отдельная ссылка на карту.

На iPhone и iPad кнопка «Сохраните дату» открывает `webcal://mt-061026.github.io/wedding.ics` в Apple Calendar: гость подтверждает подписку на календарь с одним событием. На других устройствах кнопка ведёт на обычный ICS-файл. Событие занимает весь день, а время сбора гостей указано в описании. При изменении даты, места или программы обновите и этот файл. Форма ответа гостей не предусмотрена.

Сайт публикуется из ветки `main` и каталога `/ (root)`. После каждого изменения проверьте страницу по HTTPS, фотографию, ссылку на карту и загрузку календарного файла.
